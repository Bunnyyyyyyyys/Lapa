# Lapa
Приложение для помощи в приобретении домашнего животного. 
На данный момент находится в разработке, присутствуют баги
Мобильное приложение для помощи в приобретении домашнего животного, реализующее функционал подбора, 
фильтрации, тестирования и взаимодействия с пользователем. Приложение разрабатывается на языке прогрммирования Kotlin с использованием базы данных Firebase и облачного хранилища Cloudinary.
